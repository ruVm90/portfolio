Sobre mí

Soy desarrollador web junior con ganas de seguir creciendo profesionalmente, aprendiendo nuevas tecnologías y afrontando nuevos retos.

Estudié Desarrollo de Aplicaciones Web (DAW) y me enfoco en el desarrollo backend utilizando tecnologías solidas como PHP o Java.

Procuro realizar tanto APIs como aplicaciones web lo más seguras posibles, implementando estrictas medidas de seguridad, gestión adecuado de sesiones y buenas prácticas, asi como patrones de diseño que garanticen el código mas sostenible y mantenible.

Diseño y optimizo bases de datos relacionales, asegurando consultas SQL eficientes y una arquitectura de datos sólida que sustenta aplicaciones de alto rendimiento.
