Funcionalidades principales

  • Sistema de registro con validación robusta de contraseñas (mayúsculas, minúsculas y números).
  • Autenticación segura con hashing BCRYPT y protección contra ataques de fuerza bruta.
  • Tokens CSRF únicos en todos los formularios para prevenir ataques Cross-Site Request Forgery.
  • Protección contra SQL Injection mediante PDO con prepared statements en todas las consultas.
  • Dashboard con lista de usuarios registrados y estadísticas del sistema.
  • Gestión segura de sesiones con regeneración de ID y destrucción completa al cerrar sesión.
  • Validación dual (frontend con JavaScript + backend con PHP) aplicando el principio de defensa en profundidad.
  • Página de error personalizada con mensajes informativos y redirección automática inteligente.
